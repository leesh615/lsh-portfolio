## 실행

## GitHub Pages
1. 새 GitHub 저장소를 만들거나 기존 **포트폴리오 저장소** 루트에 파일을 업로드합니다.
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` 선택 후 저장합니다.
3. 몇 분 뒤 GitHub Pages URL을 확인합니다.

> 유한양행 재무분석 저장소(`yuhan_dart`)에 이 파일을 덮어쓰지 마세요. 별도의 포트폴리오 저장소에 게시하세요.
